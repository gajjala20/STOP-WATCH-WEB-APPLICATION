# STOP-WATCH-WEB-APPLICATION


---

Task 02 Overview – Stopwatch Web Application

As part of my internship at SkillCraft Technology, I completed Task 02, which involved developing a fully functional and user-friendly stopwatch web application.


---

Features Implemented:

Start: Initiates the stopwatch timer.

Pause: Temporarily halts the stopwatch without resetting the time.

Reset: Resets the stopwatch to 00:00:00.

Lap Tracking: Records and displays lap times for each interval tracked.



---

Technologies Used:

HTML – To structure the web page.

CSS – For styling and responsive UI.

JavaScript – For stopwatch logic, DOM manipulation, and lap time functionality.
